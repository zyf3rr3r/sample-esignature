Installation Guide

  1. Click Copy Formatted Signature (or open the downloaded .html file and press Ctrl + A, then Ctrl + C).
  2. In Outlook, go to Settings > Accounts > Signatures (or File > Options > Mail > Signatures in Classic Outlook).
  3. Create a new signature, paste (Ctrl + V), assign it to new messages and replies, and click Save.
  1. Click Copy Formatted Signature.
  2. In Apple Mail, open Settings > Signatures and click +.
  3. Select all (Cmd + A), delete default text, and paste (Cmd + V).
  4. Uncheck Always match my default message font at the bottom.
Images appear as blank boxes inside Apple Mail Settings, but load properly when composing new emails.
  1. Click Copy Formatted Signature.
  2. In Gmail, open Settings (gear icon) > See all settings > General > Signature.
  3. Click Create new, paste (Ctrl + V or Cmd + V), check Insert signature before quoted text, and click Save Changes.
